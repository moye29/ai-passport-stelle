# 角色陪伴应用

为 FoloToy AI Passport 制作的三按键角色陪伴应用。使用或开发本项目无需了解原游戏剧情、
设定或战斗机制。功能概览与素材声明见[项目 README](../README.zh_CN.md)。

## 页面与操作

主页导航为 **Focus / Days / Chat / Play / Battle / Settings**。
UP、DOWN 选择功能，OK 进入；长按为 500 毫秒。息屏后的第一次按键只唤醒屏幕。
设置与聊天历史使用独立详情页。

| 功能 | 行为 |
| --- | --- |
| Focus 专注 | 固定 25 分钟倒计时或正计时，暂停／继续，停止与重置确认 |
| Days 日历 | 每日累计专注时长、完成次数与开服纪念页 |
| Chat 对话 | 手动启动一次语音交流，本地文字历史；见[聊天说明](stelle-chat.zh_CN.md) |
| Play 互动 | 打招呼、加油、跳跃与挥棒，部分动作含声音 |
| Battle 战斗 | 按 OK 打击，怪物轮换，保存累计打击次数 |
| Settings 设置 | 亮度、音量、息屏、Wi-Fi 与场景选择 |

**Path Energy** 是累计打击次数的屏幕名称。**Trailblaze** 是每日随机场景模式。
Room、Train 是固定场景，按白天／黄昏／夜间／深夜显示不同背景。
取得本地时间后，随机场景每天更换一次；应用该场景模式时也会选择一张场景。

角色通常播放待机动画；取得本地时间后，08:00 前使用睡眠待机。
Play、Chat、Battle 中保持站立。开机与亮屏时，人物展示页播放一秒打招呼；
主动按键操作优先。专注完成时播放庆祝动作。

Battle 从迎击等待开始，OK 显示怪物，再按 OK 记录一次打击。
命中与收势各持续 250 毫秒，期间输入丢弃，收势后自动轮换怪物。
命中阶段外可按 UP 清零，长按 OK 退出。保存失败会撤回计数更新并允许重试。
达到无符号 32 位整数上限后不再增加。

## 保存数据与时间

设置、每日专注记录与打击计数使用 NVS。专注记录为 366 个日期槽位的循环表，
在会话事件与周期检查点保存；只有已保存的数据保证断电后保留，不会将中断的计时
自动恢复为运行状态。存储错误不会触发自动擦除。

硬件没有已验证的后备实时时钟。开机及周期联网校时确定本地时间；未知时显示 `--:--`。
Wi-Fi 通过设备显示的热点与本地网页配置，日志不输出网络凭据。聊天历史使用独立分区。

息屏仅关闭背光，不是 MCU 深度睡眠。充电提示由 USB／电池测量推断，并非独立充电状态引脚。

## 代码结构

| 路径 | 职责 |
| --- | --- |
| `main/app_model.*` | 导航、专注、场景选择、打击计数与按键状态 |
| `main/companion_model.*` | 动作状态与时长 |
| `main/pet_view.c`、`main/ui_*.c` | LVGL 视图、文案与视觉参数 |
| `main/app_store.*`、`main/focus_log.*` | 设置与每日记录保存 |
| `main/net.*`、`main/net_form.*` | Wi-Fi 配置与校时 |
| `main/chat_*.c` | 对话传输、有界历史、编解码内存与存储 |
| `components/bsp/` | 屏幕、按键、音频、电池与共享总线 |

LVGL 任务外访问界面必须持有 `bsp_lvgl_lock()`。按键回调仅投递事件，不阻塞。
音频与网络不在 UI 回调中执行。删除界面前必须停止所有可访问它的任务、计时器与回调。

## 素材与构建

有效输入与可复现工具见[素材指南](../assets/README.zh_CN.md)。
`device/sprites.json` 定义当前帧路径与时长；替换角色应以此清单为准。
除非明确修改格式，否则保留尺寸、透明度、资源格式及分区边界。

使用 ESP-IDF 5.5.3、Python 与 Pillow，构建前生成两份资源镜像：

```sh
python tools/make_asset_pack.py
python tools/prepare_trailblaze.py --check
python tools/make_trailblaze_pack.py
./tools/validate.sh --static
./tools/validate.sh --firmware
```

[分区表](../partitions.csv) 分开保留应用、设备身份、图片与聊天记录区域。
更新设备须遵循[烧录与数据策略](development/engineering/firmware-layout.zh_CN.md)。
完整合并镜像可能覆盖已存数据；预留 Recovery 区域不代表自带恢复镜像或自动回滚。

## 验证边界

主机测试覆盖状态转换、当前素材几何与解码、存储恢复、有界历史及协议解析。
原生预览使用真实模型与视图，并提供模拟状态；不能代替硬件验收。
发布稳定版前应实测屏幕、按键、音频、网络绑定、连续对话、亮屏和断电保存行为。
