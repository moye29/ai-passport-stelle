# 人物与场景素材

当前固件以 `device/sprites.json` 作为帧路径与时长索引。
`device/frames/` 保存有效动作输入，`device/prepared/` 保存挥棒与睡眠转换结果。
重新生成资源包时须保留这些输入。

`source/` 只保留选定背景、纪念图、场景选择图、随机场景与怪物输入。
`device/anniversary/` 为设备尺寸的八帧动画，
`device/battle/` 与 `device/trailblaze/` 为处理后的资源。
命令见[素材指南](../../README.zh_CN.md)，权利说明见
[项目素材声明](../../../README.zh_CN.md#致谢与素材说明)。
